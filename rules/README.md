## 术语与资料范围

本记录采用简中官方术语。每条规则的来源在对应小节中列出；PDF 页码均为**从 1 开始的文件页序**。

卡面与基本规则不一致时的优先级、更新效果的优先使用，见进阶指南Ⅱ A。查询具体卡牌效果时，结合该张卡牌的有效说明和官方更新。

本目录保存自行整理的规则笔记与来源元数据。核验原图时，按来源清单从官方获取原件，保存到 `data/rule-sources/`，并按相应权利方条款使用。
