# 官方规则来源清单

历史资料记录日期：2026-10-27（Asia/Shanghai）。来源仅为用户指定的中国宝可梦官网及其链接的官方资源域名。

`manifest.json` 保存官方 URL、历史原件文件名、字节数、SHA-256 及 PDF 页数。历史文件名用于辨识来源，原件按清单从官方获取；含临时签名的下载链接可从对应官方详情页重新取得。

核对原件时，按官方条款获取并保存到被 Git 忽略的 `data/rule-sources/`。使用历史版本前核对散列；新版本单独记录来源和散列，保留历史值。官方资料按相应权利方条款使用。

PDF 文本提取可能改变能量图标、胜负表圆点或特殊字体的显示。核对这些内容时使用原版图形。

主阅读记录见 [上级目录](../README.md)。
