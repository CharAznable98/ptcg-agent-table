# 赛场规则与处罚记录

资料集合：`cn-official-2026-10-27`。本文件覆盖 [赛场规则 Ver.3.1.0](https://www.pokemon.cn/misc/21184.html) 全部 22 页，以及 [赛事处罚方案速查表](https://www.pokemon.cn/misc/21290.html) 1 页。原始 PDF 的官方地址和历史散列见[来源清单](./sources/manifest.json)，仓库不保存原件。规则事实采用自行整理的表述，PDF 页码从 1 开始。

这些资料适用于官方赛事，涵盖比赛流程、参与人员、现场操作及处罚。

## 1. 版本与适用范围

赛场规则自身最后更新日为 **2026-04-02**，版本 **3.1.0**。处罚表详情页日期是 **2025-12-04**，表格内落款是 **2024-07-08**；三者都如实记录，不将附件所在目录日期当作规则修订日。

赛场规则是官方活动通用规范，各具体赛事还可有卡池、比赛形式、时间和胜负处理等规定。速查表提供常见情形的参考处罚，具体裁定还取决于违规影响及实际情况。

## 3. 信息、笔记和洗牌

来源：第 2、8、9 章，PDF 第 3–4、11–15 页。

双方要表达意图并确认歧义，不能把不确定的操作擅自解释成对自己有利的结果。官方禁止从外部来源接受当前对局帮助、随意查看自己牌库/奖赏或对手非公开区域，以及使用不必要电子设备等。

笔记允许使用当场纸笔，开始时不得含预先有效信息；同一多局制对局内可以参考此前笔记，下一轮对局不能继续用上一轮有效信息，队友间也不能共用笔记。笔记不能以暗号妨碍裁判理解。

洗牌要求充分随机，牌面不可见；分堆本身并不足以随机。对手最后洗/切后，持有者不能再自行洗/切；裁判洗牌后玩家也不能再洗/切。对局开始前、多局制每场之间、第一次检索牌库后及后续洗牌，原文有不同参考建议，均非可被恶意利用的硬次数配额。

连续使用检索牌库的效果时，可以告知对手仍需使用牌库而暂不洗；停止检索或将要从顶部抽牌等之前必须充分重洗。是否在在线模式保留这个物理操作优化，不在本规则阅读任务中决定。

## 4. 开局的严格时序

来源：第 11 章，PDF 第 15–17 页；进阶Ⅰ G，PDF 第 17–18 页。

无基础宝可梦时先立即告知，不立即展示：双方都无基础则一起展示并重来；只有一方无基础则等对方先摆战斗宝可梦和奖赏卡，再展示、放回、重洗。两边共同重抽抵消，单边额外重抽次数共同记录。

补抽方必须先确定总张数，再一并抽取、查看，不能看一张再决定下一张。补抽后可以追加备战基础宝可梦，但不能取回已放置的初始宝可梦、也不能互换初始战斗与备战位置。

第 11.3 条提供极端情况下的裁判流程：9 次及以上重抽仍没有基础宝可梦时，可以呼叫主裁判；不是玩家自行宣告必然启动。主裁确认卡组及情况，记额外重抽次数 X；洗牌后从顶部翻到首张基础宝可梦，记翻过张数 Y；留该基础宝可梦，重洗其余牌并抽 6 张补足 7 张起手。对手最多补抽 **X + ceil(Y / 7)** 张，之后主裁宣布正常继续，必要时补时。

## 5. 操作用时与结束

来源：第 10、12、13 章，PDF 第 15、17–18 页。

| 项目 | 官方参考用时 |
| --- | --- |
| 开局/两场间洗牌和准备 | 120 秒 |
| 前期第一次查看牌库 | 90 秒 |
| 前期首次查看后的洗牌 | 20 秒 |
| 中后期查看牌库/洗牌 | 各 15 秒 |
| 执行卡文/招式说明 | 15 秒 |
| 下一张卡、特性或目标的思考 | 10 秒 |
| 对手回合结束后开始自己回合 | 5 秒 |

这些数值是合理节奏的参考。故意把操作拆小、每一步都耗尽参考时间可能构成拖延。

认输、合意平手不应涉及对价。弃赛影响之后配对，当前已配对但尚未记录胜负时通常算弃赛方败北；已记录完成的上一轮结果不因此改变。疑难结果由主裁/主办方处理，具体加时与胜负须看赛事细则。

## 6. 场面恢复和处罚的真实边界

来源：第 15 章，PDF 第 18–22 页；处罚速查表全部 1 页，已核对表格布局。

| 等级 | 主要含义 |
| --- | --- |
| 告诫 | 对局影响轻微或主要影响现场秩序的行为 |
| 警告 | 场面可恢复、未造成明显优势等，仍须结合影响与反复情况 |
| 奖赏卡/复数奖赏卡惩罚 | 场面难以恢复或重复违规等；惩罚可改变对手获胜所需的剩余奖赏卡阈值 |
| 败北 | 对完整性或胜负有重大影响，不适合继续/认可；可区分 game loss 与 match loss，团队赛还分个人/团队 |
| 取消资格 | 严重违规、作弊、严重不道德或其他重大破坏公平/运营行为 |
| 禁赛 | 严重个案还可追溯、追加一定期间乃至更长范围的参赛限制 |

奖赏卡惩罚不是简单“让对手立刻抽几张奖赏”。赛场规则规定，在该局中，对手剩余奖赏卡数量小于等于裁判确定的 X 张即可判胜，具体参数取决于裁判和情形。

多抽牌但未混入手牌、可以明确辨认多抽卡，与已混入且无法区分的情形，处罚可能不同。把本来随机未知的状态恢复成另一随机未知状态，也不同于把无法达成共识的状态直接改造成随机状态。漏拿奖赏未产生影响、与已经继续多回合才发现，也不能视作同一情况。

处罚速查表的例子不是穷尽规则，赛场规则明确允许根据相同事件的具体情况调整处罚。错误可能导致场面恢复、警告、奖赏卡惩罚或败北，具体处理依裁判对影响程度和实际情况的判断。
