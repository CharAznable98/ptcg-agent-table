# PTCG 规则基准

版本集合：`cn-official-2026-10-27`。来源、版本与阅读范围见 [目录说明](./README.md)。所有“一般”“通常”的限制均须结合卡面例外解释。

## 1. 规则解释的基本原则

来源：[进阶指南](https://www.pokemon.cn/misc/21231.html)，Ⅱ A，PDF 第 19 页。

卡牌说明与基本玩法不同，采用卡牌说明；有效效果已经更新时，采用更新后的说明。允许与禁止效果同时适用时，禁止效果优先。

效果中有部分无法执行，通常继续执行可以完成的部分；这不代表可以跳过使用条件或费用。带有先后依赖的说明要另查相应条目，尤其是“然后”。指定数量不能随意减少，数量不足、分类检索、非公开区域和“最多”的具体例外见 [说明文语义](./卡牌说明文语义.md)。

训练家卡、宣告使用的特性及竞技场效果，存在使用条件、且使用前可确定不会造成任何情况变化时的限制；不能简单解释为“任何卡都可以空放”。招式的处理与这些条件也不能一概等同。

## 2. 卡牌、卡组和物品

来源：[卡牌介绍](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules01/)、[所需物品](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules02/)、[构筑说明](https://www.pokemon.cn/tcg-deck-first-deck)；进阶Ⅰ A/B/C，PDF 第 5–14 页。

### 2.1 卡组的一般构筑要求

| 项目 | 规则 |
| --- | --- |
| 总数 | 恰好 60 张 |
| 基础宝可梦 | 至少 1 张 |
| 同名卡 | 一般最多 4 张；基本能量不受这个同名数量限制，特殊规则另论 |
| 同名的判断 | 比较规则意义的卡牌名；同种宝可梦的普通卡、ex、V 等未必同名；异画也不自动成为不同名 |
| 卡池 | 还须符合采用赛制、禁用范围、特殊构筑限制与有效卡文 |
、看，
教学页面推荐的能量/训练家数量与属性搭配属于建议，不是卡组合法性的额外要求。初始卡组 60 张不等于对局中牌库、手牌或某个区域始终须有固定张数。

### 2.2 宝可梦卡

与玩法有关的信息包括卡牌名、HP、属性、进化阶段和进化来源、特性、招式及所需能量、伤害和说明、弱点、抗性、撤退所需能量、特别规则。赛制标记、商品编号、卡牌序号还用于辨认版本与可用范围；稀有度、图鉴文字、插画师等不直接代替玩法效果。

一般的进化路径为基础、1 阶、2 阶。卡牌叠放构成进化后的宝可梦；它不能被简单视为几只独立在场宝可梦。卡牌正反面和当前是否可被某位玩家查看，是不同于所有权的信息。

### 2.3 能量

| 概念 | 规则 |
| --- | --- |
| 普通附能 | 每个自己的回合，可从手牌向自己场上的一只宝可梦附着 1 张能量卡；效果附能另按卡文 |
| 附着数量 | 一只宝可梦身上的能量卡没有一般张数上限 |
| 使用招式 | 能量满足招式条件即可；没有额外指示时，攻击不会自动消耗能量卡 |
| 进化与离开战斗场 | 进化及撤退保留附着能量；撤退时仅支付所需能量，昏厥等另行处理 |
| 卡与能量 | 一张特殊能量卡可能提供多个或多种能量，卡牌张数不能直接当作能量数量 |

无色不是一种基本能量卡。进阶指南列出历史整体范围内 9 种基本能量；赛制页当前标准范围则写 8 种，属于适用范围差别，不能混写成无条件的全局结论。属性图标以原 PDF/卡面为准，不能使用提取文本中的数字符号替代。

### 2.4 训练家四类

| 类别 | 一般使用方式 |
| --- | --- |
| 物品 | 自己的回合可用任意张；满足条件、展示、执行效果，再进入自己的弃牌区 |
| 宝可梦道具 | 可放到自己场上的宝可梦身上；每只一般最多 1 张；不可凭意愿随意移除或用另一张替换；进化、撤退后继续附着 |
| 支援者 | 每个自己的回合 1 张；先攻最初回合不可使用；执行后进入弃牌区 |
| 竞技场 | 每个自己的回合一般从手牌使出 1 张；在场持续生效；不能使出与现存竞技场同名的卡；不同名竞技场替换时，旧卡进入其持有者弃牌区 |

旧系列卡面可能把宝可梦道具标成物品；进阶指南明确：它们现在属于宝可梦道具，不再属于物品。道具、竞技场和特性可能自动生效，也可能需要宣告使用；自动效果不能由玩家自行选择关闭。

### 2.5 对战物品

实体玩法使用硬币、伤害指示物、中毒/灼伤标记与标有区域的卡垫。硬币不足以有效随机、落出双方可见范围等须重掷。伤害指示物表示累计受到的伤害，通常 1 个基础单位为 10 点；最大 HP、剩余 HP 与指示物数量是不同概念。

## 3. 区域和信息可见性

来源：[场上各区域](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules03/)、[准备与手牌](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules04/)；进阶Ⅰ H、Ⅱ C-20，PDF 第 18、41 页；赛场规则 2.2。

| 区域/对象 | 一般用途 | 通常可查看的内容 |
| --- | --- | --- |
| 自己手牌 | 待使用卡牌 | 自己可看正面；对手可确认数量，通常不能看正面 |
| 对手手牌 | 同上 | 通常只可确认数量；卡牌效果授予查看时另论 |
| 牌库 | 有顺序的反面牌叠 | 双方都不可随意查看正面或私自整理顺序，包括自己的牌库 |
| 奖赏卡 | 开局放置、满足条件后拿取 | 通常反面朝上；自己也不能随意查看正面；选择拿取顺序不等于可以预先查看 |
| 战斗场 | 战斗宝可梦所在位置 | 对局开始翻面后通常公开；开局准备时先反面摆放 |
| 备战区 | 可替换上场的宝可梦 | 通常公开；一般最多 5 只，须考虑卡面例外；准备时先反面摆放 |
| 弃牌区 | 已用、丢弃、昏厥等卡牌 | 公开区域；卡牌进入其持有者的弃牌区 |
| 竞技场卡 | 双方共享适用的场地效果 | 在场时公开，保留卡牌所属方以便替换时弃置 |
| 放逐区 | 特定卡牌或效果涉及的去向 | 不从主教学的六个区域推导全部细节；只在相应卡池/卡文范围采用已明确的规则 |

规则术语“场上”只指战斗场和备战区，不是整张桌面全部区域。手牌没有一般数量上限。

卡牌效果可以临时授权查看非公开信息。除非说明要求展示给对手，否则使用查看效果不自动等于双方公开；查看结束后的翻面、位置、重洗按卡文处理。查看奖赏卡后反面放回时，进阶指南允许在奖赏卡区域内另选位置。

## 4. 对战准备

来源：[对战准备](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules04/)；进阶Ⅰ G，PDF 第 17–18 页；更严格赛事时序见 [赛场摘要](./赛场规则摘要.md)第 4 节。

| 顺序 | 操作及限制 |
| --- | --- |
| 1 | 友好问候；通过猜拳等方式决定选择权，由胜方选择先攻或后攻 |
| 2 | 各自充分洗牌，反面朝上放为牌库 |
| 3 | 各从牌库顶部抽 7 张起手 |
| 4 | 依先攻、后攻顺序告知有无基础宝可梦；有则选 1 张反面放在战斗场 |
| 5 | 可将剩余起手中的基础宝可梦反面放入备战区，一般至多 5 只，也可以不放 |
| 6 | 从牌库顶部放 6 张反面奖赏卡；按重抽情况处理可选补抽 |
| 7 | 双方准备完成，将战斗和备战宝可梦翻正，对战开始；先攻开始第一个回合 |

网页重复展示“放置宝可梦（1）/（2）”不是放两只战斗宝可梦的规则。

### 4.1 无基础宝可梦的重抽

双方都没有基础宝可梦时，双方展示起手验证，再一起放回、洗牌、重抽；这种共同重抽不直接产生一方的额外补抽优势。

只有一方没有时，有基础宝可梦的一方先完成初始摆放至奖赏卡；另一方再展示无基础的 7 张牌，放回牌库、洗牌、重抽，直到成功。非重抽方可以补抽不超过对方相应单方重抽次数的卡，也可不抽。

补抽数量须先一次性宣告，再一起抽取；不能边看新增手牌边决定继续抽几张。新增基础宝可梦可以用于追加备战。赛场规则还明确此时不能取回已摆好的初始宝可梦或互换初始战斗和备战位置。

## 5. 回合与基础玩法

来源：[对战方式](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules05/)；进阶Ⅰ A/B/C，PDF 第 5–14 页。

### 5.1 回合顺序

| 环节 | 一般规则 |
| --- | --- |
| 回合最初 | 必须先从自己牌库顶部抽 1 张；此时已无牌可抽则败北 |
| 回合内 | 在满足相应条件的前提下，选择附能、放基础宝可梦、使用训练家、进化、使用特性、撤退等；不是强制按教学列举顺序各做一次 |
| 回合结束 | 使用战斗宝可梦招式并完成相关处理后结束；也可以不攻击，宣告结束 |
| 回合之间 | 执行双方的宝可梦检查，完成后才开始另一方回合 |

成功抽到牌库最后一张不会立即败北；回合内效果抽牌也不能套用“牌库空了就立刻输”。先攻的最初回合不能使用招式，也不能使用支援者；先后攻双方的各自最初回合一般都不能进化。

### 5.2 放置与进化

自己的回合可以把手牌基础宝可梦逐只放入备战区，只要有合法空间。不是全回合只能放一只，也不能把普通进化卡当基础直接放置。

进化须对应当前宝可梦的进化来源；战斗场和备战区都可以进化。本回合刚出场或刚进化的一只通常不能继续进化。一般没有“每回合只能进化一只”的全局限制。

进化保留伤害指示物、能量、宝可梦道具等；清除相应特殊状态和先前受到的招式效果。进化后通常不能再用被覆盖的卡牌的招式与特性，除非卡文给予例外。伤害数量保留不等于剩余 HP 数值保持不变。

### 5.3 特性与持续效果

主动特性须符合位置、时机、条件、次数等卡面说明，宣告后按顺序执行。被动特性在条件成立时自动生效。使用特性通常不结束回合，但具体效果可以结束回合。

不同宝可梦的特性次数可以独立计数，卡文也可规定同名特性共享次数限制；离场后再出场及继承使用记录的处理另有规定，见进阶Ⅱ E-12～E-17、D-19。

### 5.4 撤退与效果互换

撤退通常每个自己的回合一次：宣告、支付能量、把战斗宝可梦与自己选定的备战宝可梦互换。需要有备战宝可梦；备战区已满一般不阻止这种互换。撤退费用按能量数量计算，不限能量属性；多能量特殊卡的支付按其含义解释。

睡眠、麻痹和相应禁止效果会阻止撤退。撤退后保留未支付掉的能量、道具与伤害指示物，清除特殊状态和受到的效果。

卡牌效果造成的互换不是撤退，一般不支付撤退费用，也不直接消耗普通撤退次数；不能因为不能撤退就认定任何交换效果都无效。由谁选择替换目标、效果作用于哪只宝可梦，按具体卡文区分。

## 6. 招式、伤害和效果

来源：[招式与伤害](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules05/)；进阶Ⅰ A-01，PDF 第 5–8 页；Ⅱ B/C 详见 [说明文语义](./卡牌说明文语义.md)。

### 6.1 招式结算顺序

| 顺序 | 内容 |
| --- | --- |
| 1 | 宣告战斗宝可梦的具体招式；须满足能量、状态与禁止条件 |
| 2 | 处理妨碍攻击的效果及混乱等使用状态确认；失败情形按各自规则处理 |
| 3 | 执行明示在造成伤害前处理的内容 |
| 4 | 按伤害计算流程计算伤害 |
| 5 | 按说明顺序处理伤害之外的效果 |
| 6 | 处理对方宝可梦受到伤害时触发的效果 |
| 7 | 在规定时点确认昏厥，处理相关结果，并结束回合 |

普通目标是对方战斗宝可梦；卡文可以选择其他宝可梦、伤害多个目标或自身。使用招式需要的能量与招式效果要求丢弃的能量是两回事。无能量要求的招式不需要为了发动而额外附能。

### 6.2 伤害计算顺序

| 顺序 | 内容 |
| --- | --- |
| 1 | 由招式数字和对应说明计算基础伤害，包括加法、乘法、减法等 |
| 2 | 应用攻击方身上附加的伤害修正 |
| 3 | 计算受击方弱点，使用卡面规定的倍率/数字 |
| 4 | 计算受击方抗性 |
| 5 | 应用受击方身上附加的伤害修正 |
| 6 | 确认最终伤害，以相应伤害指示物表示；不受伤害等保护按对应规则处理 |

在相应步骤降至 0 或负数时，按规则停止伤害计算，不能简单把后续增伤继续加回。备战宝可梦受到招式伤害一般不计算弱点、抗性。无视附加效果与不计算弱点/抗性不是同一规则。

**造成伤害与通过效果放置/转移伤害指示物不同。** 后者不直接套用伤害的弱点、抗性和防伤流程；不受伤害和不受招式效果也分别判断。最终都是指示物变更，不代表规则语义相同。

“招式失败”还须区分使用前因对手效果/混乱而失败与招式自身说明导致的失败，是否算已使用该招式不同，详见Ⅱ D-01。

## 7. 宝可梦检查与特殊状态

来源：[检查和特殊状态](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules07/)；进阶Ⅰ F，PDF 第 16 页。

### 7.1 宝可梦检查

检查发生在双方回合之间，**不属于任一玩家的回合**，双方宝可梦都须处理。

特殊状态检查的相对顺序为中毒、灼伤、睡眠、麻痹。检查时生效的特性和训练家效果可安排在特殊状态检查之前或之后；这些效果的顺序由受到效果的宝可梦持有者决定。不能据教学网页的概述就把所有项目理解成任意排序。

检查相关处理末尾确认昏厥并处理，之后才进入下一方回合。混乱不是在检查中掷币。

### 7.2 五种特殊状态

| 状态 | 一般效果与恢复 | 攻击/撤退 |
| --- | --- | --- |
| 中毒 | 每次检查放 1 个基础伤害指示物，即 10 点；有相应卡文时数量可以改变 | 通常均可 |
| 灼伤 | 每次检查先放 2 个，即 20 点；再由持有者掷币，正面恢复、反面保留；卡文可改变数量 | 通常均可 |
| 睡眠 | 每次检查由持有者掷币，正面恢复、反面继续 | 不可使用招式、不可撤退 |
| 麻痹 | 在自己的下一个回合结束后的检查恢复，不是每次检查都恢复 | 不可使用招式、不可撤退 |
| 混乱 | 使用招式前掷币；正面继续，反面失败，自身放 3 个即 30 点并结束回合 | 可撤退；攻击须掷币 |

中毒、灼伤可以彼此及与其他特殊状态并存；睡眠、麻痹、混乱三者互相替换。

回到备战区、进化，以及明确恢复状态的卡牌效果，可以恢复相应特殊状态。实体卡方向和状态标记用于表示状态；它们不是全部临时效果的通用替代。

## 8. 昏厥、奖赏与胜负

来源：[昏厥和获胜](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules06/)；进阶Ⅰ D/E，PDF 第 14–16 页。下面的同时胜负表已对照 PDF 第 15 页图像核验，未仅依赖文本提取。

### 8.1 昏厥确认与处理

宝可梦因伤害、效果或特殊状态等没有剩余 HP 时进入昏厥处理。累计伤害大于或等于当前有效最大 HP，即剩余 HP 小于或等于 0；当前最大 HP 包含仍然生效的 HP 修正。退化后以退化后的当前最大 HP 与继承的累计伤害比较。确认时点包括招式/特性/训练家等相关处理的末尾、宝可梦检查相关处理的末尾，以及其他没有剩余 HP 的相应情况。

按规定处理昏厥时生效的效果，再将昏厥宝可梦及身上所有卡牌放入持有者弃牌区，双方拿取与对手昏厥对应的奖赏卡。一般每只 1 张；ex、V、TAG TEAM 等特别规则会改变数量。拿的是自己放置的奖赏卡，不是对手区域的卡。

战斗宝可梦昏厥后，由持有者选备战宝可梦上场。双方战斗宝可梦同时昏厥时，下一回合将轮到的玩家先放置新的战斗宝可梦。

### 8.2 胜负条件与时点

| 事件 | 一般结果 |
| --- | --- |
| 玩家拿完自己的奖赏卡 | 该玩家获胜 |
| 玩家场上没有宝可梦/没有可作为战斗宝可梦的宝可梦 | 该玩家败北；同时满足情形另按下表 |
| 自己回合最初因牌库无卡无法抽牌 | 该玩家败北 |
| 玩家认输 | 对手获胜 |

在招式、特性或训练家等处理期间达到胜负条件，要先完成相关处理，再判胜负。卡文也可能明确规定胜利或败北，见Ⅱ E-38。

### 8.3 同时满足条件

定义 A＝自己拿完奖赏，B＝对手拿完奖赏，C＝自己没有可上场宝可梦，D＝对手没有可上场宝可梦。下表 `1` 表示该行条件成立，`0` 表示该行未标记；逐行记录官方表，不扩张为对任意其他终止原因都适用的通用公式。

| A | B | C | D | 结果 |
| --- | --- | --- | --- | --- |
| 1 | 0 | 1 | 0 | 平局 |
| 0 | 1 | 0 | 1 | 平局 |
| 1 | 1 | 1 | 1 | 平局 |
| 1 | 1 | 0 | 0 | 平局 |
| 0 | 0 | 1 | 1 | 平局 |
| 1 | 1 | 0 | 1 | 自己获胜 |
| 1 | 0 | 1 | 1 | 自己获胜 |
| 1 | 0 | 0 | 1 | 自己获胜 |
| 1 | 1 | 1 | 0 | 自己败北 |
| 0 | 1 | 1 | 1 | 自己败北 |
| 0 | 1 | 1 | 0 | 自己败北 |

普通规则允许平局。若双方希望一定分胜负，进阶指南给出抢分赛：重新开局，仅放 1 张奖赏卡，先满足胜负条件者获胜。

## 9. 牌库、数量和信息操作

来源：进阶Ⅰ H，PDF 第 18 页；Ⅱ C-20、D-02～D-05、E-33～E-36；详细语义见 [说明文语义](./卡牌说明文语义.md)。

“抽牌”一般指从顶部不预先看正面地移入手牌；“选择牌库中的卡牌”可以授权查看牌库正面，但不自动授权向对手展示全牌库。选择有类别限制的非公开卡牌时，少选或不选的例外与选择任意卡牌的足额要求不同，不能统一处理成“有就必须全选”或“任何最多都允许 0”。

查看后是否展示所选卡、是否重洗、是否返回原位/任意奖赏位置，须按具体说明。洗牌要求双方不能辨认顺序，不能一边重洗一边保留对未来顺序的可见信息；效果明确排顶/排底等另按说明。

附着/转附能量的“张”与“个”、基础宝可梦“放置”与“从手牌使出”、进化与退化、最大 HP 变化与伤害数量、对宝可梦与对玩家施加效果，均有不同规则语义。

## 10. 特殊卡牌与赛制范围

来源：[主卡牌介绍](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules01/)、[其他赛制特别卡牌](https://www.pokemon.cn/tcg-rules-regulation-extra/)、[赛制](https://www.pokemon.cn/tcg-rules-regulation/)。

| 类别 | 官方页面说明的特别点 |
| --- | --- |
| 宝可梦 ex | 与不带 ex 的名称不同；一般昏厥对应 2 张奖赏 |
| 宝可梦 GX | 名称区分；一般 2 张奖赏；GX 招式的次数与失败语义要结合具体说明核对 |
| TAG TEAM 宝可梦 GX | 标签用于效果识别；一般 3 张奖赏；GX 招式有追加条件 |
| TAG TEAM 训练家 | 标签本身不额外生成一套规则；使用时先宣告只执行首段还是执行全部效果 |
| 宝可梦 V | 一般 2 张奖赏；卡文指 V 时还包含 VSTAR、VMAX |
| 宝可梦 VSTAR | 由 V 进化，一般 2 张奖赏；使用 VSTAR 力量后翻面自己的 VSTAR 标记 |
| 宝可梦 VMAX | 由 V 进化，一般 3 张奖赏 |
| 棱镜之星 | 同名此类卡一副只放 1 张；将进入弃牌区时改放逐区，可能存在于宝可梦/训练家/特殊能量 |
| 光辉宝可梦 | 一副总共只放 1 张光辉宝可梦，不只是每个名称各 1 张 |
| 究极异兽 | 标签用于识别，本身没有额外统一特别规则 |
| V-UNION | 官方补充页将其列为拥有规则的宝可梦，但该页没有完整展开其使用细节；不能只凭列名推导出场流程 |

官方特殊牌页面对 GX、VSTAR 的个别总体次数规则、部分新机制未完整展开，相关规则仍须以有效卡面及官方补充核对。本表不覆盖所有特别机制。
