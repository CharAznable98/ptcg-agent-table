# PTCG 简体中文卡牌说明文语义

记录日期：2026-10-27。本文整理简中官方卡牌说明文规则及其来源。

## 来源与覆盖范围

来源为中国官网[《进阶玩家向规则指南 Ver.3.1.0》落地页](https://www.pokemon.cn/misc/21231.html)。原件来源和历史散列见[来源清单](sources/manifest.json)，核对原图时从官方独立获取；本仓库不保存原件或全文提取。以下页码均指 PDF 的实际页序，从 1 开始。

本次逐页阅读第 19–76 页，覆盖第二部分的全部 A、B-01～B-09、C-01～C-20、D-01～D-19、E-01～E-39。相关第一部分基础规则应与主记录一同阅读。基础玩法网页将进阶指南标注为 2025-03-21 更新；PDF 资源地址中的上传日期不另行视为规则生效日期。

本文用自己的话整理可执行的规则事实，不复刻原文的卡牌例文。卡牌个别说明、后续勘误仍须读取相应官方文本，不能只凭这里的通用解释推断全部效果。

## A. 解释牌文的总原则

来源：官方指南 Ⅱ-A，PDF 第 19 页。

| 事项 | 规则事实 |
| --- | --- |
| 牌文与一般规则 | 卡牌写明的例外优先于一般规则。已经更新过效果的卡牌使用更新后的效果。 |
| 允许与禁止同时存在 | 对同一事项同时存在允许执行与禁止执行的效果时，以禁止执行为准。具体写明可绕过某项一般限制的牌文仍需按其范围解释，不能据此认为所有禁令均被绕过。 |
| 部分无法执行 | 原则上执行能够执行的部分，不执行无法执行的部分。另有使用条件、连接词或处理指示的，遵从那些限制；不能把这个原则当成免付使用条件。 |
| 指定数量 | 数量原则上不能自行减少；对象不足时尽可能接近指定数。公开区域、分类检索、未限定种类的选择有不同细则，分别参照 Ⅰ-H、Ⅱ-D-04/D-05、E-33/E-34。 |

## B. 伤害相关牌文

| 编号与页码 | 语义与处理要点 |
| --- | --- |
| B-01，第 19–20 页 | 按条件追加固定伤害，是招式基础伤害的计算内容，在伤害计算第 1 步处理，不当成附加于宝可梦的招式效果。 |
| B-02，第 20 页 | 以对象数、成功次数等乘以单位伤害，同样属于伤害计算第 1 步。算出 0 后即停止计算，后面的攻击方加伤效果不能把它重新变为正伤害。 |
| B-03，第 20 页 | 由基础伤害扣减所指定的数值，也在伤害计算第 1 步处理。结果为 0 时停止，不能再靠后续攻击方加伤补回。负数的处理同时参照第一部分的伤害计算步骤。 |
| B-04，第 21 页 | 额外的加伤效果与基础伤害里的加法不同。附加于攻击方的加伤在第 2 步计算，同步骤多个效果合计；若效果实际附加于承伤方，则在第 5 步算，不能只看正负号决定位置。 |
| B-05，第 21–22 页 | 减伤效果通常在承伤方效果的第 5 步计算并合计；附加于攻击方的降伤则在第 2 步。应先识别效果承载对象，再确定计算步骤。 |
| B-06，第 22 页 | 明文不计算弱点或抗性时跳过所指定的步骤。招式中这种伤害计算说明不是可单独抵抗的招式效果。 |
| B-07，第 22–24 页 | 忽略承伤宝可梦身上附加效果的伤害，可以绕过承伤方的加减伤及伤害免疫。但不会因此恢复已经被其他效果改变或消除的弱点、抗性；对弱点、抗性的计算说明不属于这里被忽略的附加效果。 |
| B-08，第 24 页 | 对选定的多个对方宝可梦分别造成招式伤害，不是直接放置指示物的效果。招式名旁的伤害数字通常只表示战斗宝可梦所受伤害；备战对象的数值看说明文。无特别指示时，备战伤害不计算弱点、抗性。可以选中伤害免疫对象，但它实际不承受伤害。 |
| B-09，第 24–25 页 | 对自己或自己备战宝可梦造成的反作用伤害仍按伤害处理，不是直接放置指示物。只防止或减少“对手招式伤害”的效果不能用于自己的招式反伤。 |

以上伤害的完整步骤顺序见主记录的攻击与伤害部分，以及官方指南 Ⅰ-A-01。尤其不要把“基础伤害的加减”“攻击方效果的加减”“承伤方效果的加减”合并成无顺序的一次运算。

## C. 效果操作语义

### C-01：弃置（第 25–26 页）

被指定的卡牌进入其持有者的弃牌区；未写明由谁选择时，由执行该效果的玩家选牌。

牌文要求弃掉若干“个能量”时，不一定等于相同张数的卡：一张提供多个能量的特殊能量，可以满足相应能量个数；即使只需弃一个能量，也必须整张弃置，不能拆开卡牌保留余量。

### C-02：返回手牌或牌库（第 26 页）

目标卡回到其持有者的相应区域。场上宝可梦返回这些区域时，移去伤害指示物并消除附加效果；若为进化宝可梦，下方的进化前卡牌随同返回。附着卡的去向应按具体效果说明处理，不能把只针对宝可梦的指示擅自解释为任何附着卡都返回。

### C-03：交换自己的战斗与备战宝可梦（第 26–27 页）

这是卡牌效果引发的交换，与规则动作“撤退”不同，不缴撤退能量，也不受单纯的无法撤退状态阻止。必须存在可换上的备战宝可梦。

换下的原战斗宝可梦所受特殊状态及招式附加效果消除。不能把移动到备战区同时解释成清掉伤害、能量或道具。

### C-04：要求对手换下战斗宝可梦（第 27–28 页）

执行效果的一方令对手原战斗宝可梦换下；由对手从原备战宝可梦中选择新战斗宝可梦。对手没有备战宝可梦时不执行。换下者清除特殊状态和招式附加效果。

该效果针对的是原战斗宝可梦。若它免受该来源的招式效果，则换不下；备战宝可梦是否免疫不是此效果的阻止条件。

### C-05：指定对手一只备战宝可梦换上（第 28–29 页）

执行效果的一方选择对手备战对象，使其与原战斗宝可梦交换。没有备战对象时不执行。原战斗宝可梦换下时清除特殊状态和招式附加效果。

此效果针对的是被选中的备战宝可梦。因此，所选备战宝可梦免受该来源的招式效果时无法交换；原战斗宝可梦有此免疫，本身不阻止这种定向拉上方式。它与 C-04 不能合并为同一种效果对象判断。

### C-06：回复 HP（第 29 页）

通过移去等量伤害指示物实现回复；已有伤害不足回复值时移去全部，回复全部 HP 也是移去全部。不能回复出超过最大 HP 的生命值。

纯回复用途的训练家卡或特性不能对完全没有伤害指示物的对象使用；同时回复多只时，至少一只有伤害即可使用。

### C-07：直接放置伤害指示物（第 29–30 页）

未另作说明时，一个指示物代表 10 点已经受到的伤害。指示物足以使剩余 HP 降至 0 或以下时会产生昏厥。

招式直接放指示物在“除伤害外的效果”步骤执行，不计算弱点、抗性、伤害加减等伤害计算项。免受招式效果的宝可梦可以被指定为对象，但不会因该招式效果被放置指示物。

### C-08：转移伤害指示物（第 30–31 页）

按指定数量从原对象移除，再转放到目标对象；无符合条件的接收对象时不能转放。它属于效果，不是一次新的伤害计算；能造成昏厥。

指南明确给出一个不能简化的边界：可以选中免受该招式效果的接收对象，但该对象不会被放入指示物；已经从原对象移去的指示物不放回原处。

### C-09：通过效果附着能量（第 31–32 页）

按指定来源、能量类别、张数和目标附着；一般只允许将自己的能量附着给自己的宝可梦。这种效果附着不占用、也不受通常每回合一次的手牌附能次数限制。

若符合“每当附着能量”等触发语句的条件，效果附着也触发。一次附着多张卡按卡牌张数分别触发；不能把一张提供多个能量的卡算成多次附着。

### C-10：转附能量（第 32–33 页）

把已有能量卡从一只场上宝可梦移到另一只，自己的能量不因此转给对手。无符合目标条件的宝可梦时不能转附。

要求转附一个能量时，可以选一张实际提供多个能量的卡；卡牌整体移动。特殊能量即使最终不允许附着于某目标，也可被选择转附到那里，然后按该特殊能量的限制弃置，不把这一步统一拒绝成“不能选择目标”。

### C-11：通过效果将宝可梦放到备战区（第 33–34 页）

按指定来源和类别选择对象；不要把标题中的基础宝可梦示意误当成所有效果都只能放基础宝可梦，具体卡文可能允许进化宝可梦直接出场。

备战已满时：只有此类放置内容的招式可以使用但不进行放置，牌库检索型在查看牌库前结束；相应用途的训练家卡或特性不能使用。空位少于指定放置数时，按实际空位放置。

### C-12：通过效果进化（第 34 页）

仍需满足效果指定的进化匹配条件，继承卡牌与伤害的方式同普通进化。除具体卡文另有限制，效果进化可以在自己的首回合、或目标刚出场的当回合进行；不能把普通进化的时点禁令无条件用于全部进化效果。

卡牌说明中的“进化卡”通常指叠在场上宝可梦上的进化阶段宝可梦卡。

### C-13：退化（第 35–36 页）

从进化叠层最上方移除指定数量的进化卡，移除卡的去向看牌文。剩余宝可梦保留附着卡和伤害指示物，清除特殊状态及附加效果。继承的累计伤害达到退化后宝可梦当前有效的最大 HP 时，进入昏厥处理；当前最大 HP 包含仍然生效的 HP 修正。

未另有指示时，退化后的宝可梦视作刚上场，当回合不能再进化。通过效果直接出场、下方没有进化前宝可梦卡的进化宝可梦不能退化。

### C-14：禁止撤退（第 36 页）

阻止规则动作撤退，但不当然阻止效果交换。招式施加的这种状态在对象返回备战、离场、进化或退化时消除。持续特性产生的限制仍须按其持续条件重新判断。

### C-15：禁止使用招式（第 36 页）

即使附着能量足够，也不能宣告被禁止的招式。只禁止特定名称时，仍可宣告其他招式。招式施加的这种限制在对象返回备战、离场、进化或退化时消除。

### C-16：免受招式伤害（第 36–37 页）

在最终伤害步骤使该对象不承受招式伤害；一次攻击多只时只保护符合条件的对象，不保护其他对象。这是附加于宝可梦的效果，因此写明忽略对象附加效果的伤害可以绕过它。

### C-17：免受招式效果（第 37–39 页）

不执行招式结算中的非伤害效果部分，伤害计算等其他步骤正常执行。可能挡住特殊状态、指示物、弃附着卡、禁止攻击或撤退、特定交换等；仍须识别效果真正针对的对象。

后来重新获得这种免疫，不会消除早已受到的招式效果或特殊状态；免疫不是事后治疗。

### C-18：使用另一个招式的内容（第 39–40 页）

执行被选招式的伤害与效果；无额外要求时不需满足被选招式自身的能量费用，但仍需满足实际宣告招式的要求。

实际使用的招式名称仍是原先宣告的招式，不自动变成被复制招式。被复制内容中无法做到的部分按一般部分执行原则处理，不能把不是前置使用条件的弃能内容擅自变成复制的能量门槛。

### C-19：禁止玩家从手牌使用某类卡（第 40–41 页）

限制附加在玩家，而不是某只宝可梦上。宝可梦的招式效果免疫不能让其持有者绕过这种出牌禁令。

### C-20：查看隐藏卡牌（第 41 页）

默认由使用效果者查看指定反面卡牌；不等于给双方公开。未另有指示时，看后仍反面放回指定位置。

奖赏卡有特殊位置规则：查看后反面放回奖赏区域时，可以换到该区域的其他位置，不要求保持原槽位；随后是否重洗仍看牌文。

## D. 通用术语

| 编号与页码 | 规则事实 |
| --- | --- |
| D-01，第 42 页 | 招式失败时不产生该招式的伤害和效果，也不能靠加伤效果救回。因对手先前施加的失败判断而失败，在宣告后的状态检查阶段判为未使用招式并结束回合；招式自己的失败条件导致失败，则算已使用招式，回合同样结束。这一区别可能被其他卡文引用。 |
| D-02，第 42–43 页 | 任意数量由执行者选择数量。若训练家卡/特性预先已知完全没有可选择对象、不会改变局面，则不能空用；不能把“任意”解释成所有情形都能空过消耗卡。 |
| D-03，第 43 页 | 全部/所有要求覆盖全部指定对象，不能自行挑选一部分。 |
| D-04，第 43–44 页 | 指定数通常须足额选择；对象不足取最接近指定数，多种对象分别尽可能选择。一个种类不存在不自动阻止其他种类。隐藏区域选择另按 Ⅰ-H、E-33、E-34；预先可知不产生任何变化的训练家卡或特性不能使用。 |
| D-05，第 44 页 | 对公开对象的“最多 N”一般可选 1 到 N；不据此统一允许选 0。隐藏区域有另行少选/不选规则；无对象且不会有任何变化的训练家卡或特性不能使用。 |
| D-06，第 44–45 页 | “拥有”招式等通常指该卡面本身写有。因道具、特性等额外获准使用的招式，不等于它拥有该招式；进化前招式被效果重新允许使用也同样不算。 |
| D-07，第 45 页 | 属性是宝可梦或能量的种类，按卡面与当前生效文本判断；有些效果使宝可梦同时拥有多种属性。不要把图示提取成的数字字符当成正式属性名称。 |
| D-08，第 46 页 | 所有属性能量同时具有指南所列的能量属性，个数按其卡文。例如一张按一个所有属性能量计，不是每种各一个；不能由玩家随意决定暂时不算某一属性来规避弃能或满足条件。 |
| D-09，第 46 页 | 招式费用由对应招式名旁的能量属性及数量表达，效果可修改。额外获准使用其他招式时，是否仍要满足该招式费用看授权效果文本。 |
| D-10，第 47 页 | 撤退费用是宝可梦卡撤退栏的能量个数，执行时实际弃置足量能量；效果可能改变当前费用。 |
| D-11，第 47 页 | 多个增加效果合计；同一数值同时有增加与减少时合并计算，不因执行顺序不同而固定只取一个。 |
| D-12，第 48 页 | 多个减少效果合计；与增加效果同时存在时合并处理。能量需求被完全消除时另按 D-13，不继续叠加增加。 |
| D-13，第 48–49 页 | 完全消除能量需求优先于同一能量需求的增加/减少。消除弱点、特性、道具效果等则按指定内容处理；例如被消除的特性不能仍拿来满足“拥有特性”的有效计数。 |
| D-14，第 49–50 页 | HP 全满表示没有伤害指示物，即当前剩余 HP 等于当前最大 HP。不能只与印刷 HP 比较。 |
| D-15，第 50 页 | 最大 HP 基于卡面 HP，并受当前在场效果影响；指南中的最大 HP 加减效果作用于场上宝可梦。 |
| D-16，第 50 页 | 剩余 HP＝当前最大 HP－已经受到的伤害。以伤害指示物记载已有伤害，不把剩余 HP 与指示物重复扣减。 |
| D-17，第 50–51 页 | 已取奖赏数按起始奖赏数量与当前剩余数量之差判断。指南分别以 60/40/30 张卡组对应用 6/4/3 作为起始奖赏基数。 |
| D-18，第 51–52 页 | 拥有规则的宝可梦以卡面写有规则框为判据，不能只按是否多取奖赏判断；构筑数量受限等规则也算。只有战斗风格标识、却无此类规则框，不因此成为拥有规则的宝可梦。 |
| D-19，第 52–53 页 | 明示继承的替换/叠放保留其指定的卡牌、指示物、特殊状态、效果等，并继承已使用特性的历史信息。同名特性可能因此不能再用；新卡的另一名称特性尚未用过则不被旧特性的使用记录一概阻止。 |

## E. 时点、条件、期限及其他说明

### E-01 / E-02：下一次某方回合（第 53 页）

分别指当前回合后紧接着的对手回合、或下一个自己的回合；这种只写某个回合的有效窗口不包括宝可梦检查。不要与“直到某方下一回合结束”的持续期限混用。

### E-03：受到招式伤害时（第 53–54 页）

至少实际受到 10 点招式伤害才符合，0 或更低不算。其后续处理在招式的伤害与非伤害效果之后、正式昏厥处理之前执行，即使此次伤害足以昏厥也先处理。

同一受伤宝可梦同时有多个此时点效果时，由其持有者决定顺序。

### E-04：昏厥时（第 54–55 页）

后续效果在昏厥处理的相应阶段、把昏厥宝可梦送入弃牌区之前处理。多只同时昏厥并有多项此阶段效果时，由相应昏厥宝可梦的持有者决定自己的效果顺序；所有这些效果执行完，再将昏厥宝可梦弃置。

累计伤害与当前有效最大 HP 比较：累计伤害大于或等于当前最大 HP，即剩余 HP 小于或等于 0，在规定时点进行昏厥处理。

### E-05：从手牌进化时（第 55 页）

必须是从手牌使出并进行进化，且在该触发时点使用。进化后先做了其他行动，就失去这次触发机会。由效果使手牌中的进化卡完成进化，也可以满足来源条件；从牌库等其他来源进化不因此自动满足。

### E-06：从手牌放到备战时（第 55–56 页）

只在从手牌放到备战区的触发时点适用；放置后先做其他行动就不能补用。不能把从弃牌区或牌库直接放到备战区当成从手牌使出。

### E-07：附着能量时（第 56–57 页）

需按触发文本识别能量来源；牌文写明从手牌附着时，普通手牌附能和从手牌进行的效果附能都能满足，来自其他区域的效果附着不能冒充手牌来源。

可选触发须在附着时使用，先做其他行动就不能补用。同一对象多个附着触发由其持有者定顺序。一张提供多个能量的卡仅触发一次；多张卡同时附着则按卡牌张数分别触发。

### E-08：每次宝可梦检查时（第 57 页）

在每次宝可梦检查执行，作为该时点的特性或训练家效果。多个效果同时影响同一方宝可梦时，由受到影响宝可梦的持有者决定其效果顺序。完整的检查步骤与特殊状态检查顺序见主记录，不能只靠本条决定全部先后。

### E-09：伤害之前（第 57–58 页）

在招式流程的伤害前效果阶段执行，早于伤害计算，晚于宣告后的失败/状态检查。被弃置的附着卡或其他改变可能因此影响随后的伤害数值。

### E-10：可选择是否执行（第 58 页）

由该效果的使用者决定是否执行可选部分；选择执行后仍依其指定数量和条件处理。无法执行前面的可选部分时，依赖“在这种情况下”的后续部分也不执行。

### E-11：上个对手回合曾昏厥（第 58–59 页）

检查指定宝可梦是否在上个对手回合符合昏厥条件；若卡文限定昏厥原因，也必须匹配该原因。多只满足不会重复放大一次性的条件后续。

这是历史条件，不是贴在当前攻击宝可梦身上的招式效果；它进出战斗场不抹掉已经发生的历史。宝可梦检查与回合分开，不把检查时昏厥自动记为对手回合内昏厥。

### E-12：每自己回合的特性次数（第 59 页）

这类特性需要宣告使用，默认对象是自己场上的宝可梦。无共享限制时，同名特性的不同宝可梦各有自己的次数。

宝可梦真正离场后重新出场，视为新的场上宝可梦，可以再次获得自己的使用次数；只在战斗场和备战区之间换位不等于离场。明示继承或全局同名限制另按 D-19、E-14。

### E-13：在场期间持续生效（第 59–60 页）

效果只在来源宝可梦满足指定位置条件时持续生效；有些限定战斗场或备战区。并非所有持续特性都会使用相同句式，必须结合完整牌文判断。

### E-14：同名特性每回合共享限制（第 60–61 页）

写明本回合已经使用其他同名特性便不能使用时，限制跨同名宝可梦共享。使用者离场也不清除该回合的同名使用事实，不能换一只或重新出场绕过。

### E-15：持续效果不叠加（第 61 页）

多只来源拥有相同且明示不叠加的效果，最终仅产生一份该效果。不能把一般同类加减的可合计原则用于明文不叠加的效果。

### E-16：特定中毒数值（第 61 页）

在每次检查中，按该次中毒定义的指示物数量处理，恢复方式与普通中毒相同。新的中毒状态覆盖原有中毒，包括普通与特殊中毒相互覆盖；不能把两个中毒数值简单相加。

### E-17：在非场上指定区域使用特性（第 61–62 页）

只在卡文指定区域满足条件时使用。通常各卡各有自己的每回合次数；离开该区域后再回来视为另一张该区域中的卡，可重新使用。若另有全回合同名限制，仍遵守共享限制。

### E-18：检索后重洗牌库（第 62 页）

查看、选择牌库中的卡后，按指示打乱顺序，避免双方掌握原顺序。即使最终没有选出卡牌，已查看过牌库仍需要重洗；不能用检索失败保留看过的顺序。

### E-19：前段与“然后”后段（第 62–63 页）

先处理前段，再处理后段。前段至少有一部分实际执行，才继续后段；前段全部未执行时不继续。后段不可执行，不自动使前段不可执行；仍按可执行部分处理。

不能把这等同于“所有部分必须都成功才允许使用”，也不能解释成无论前段是否发生都执行后段。涉及训练家卡和特性空用限制时还须检查能否合法开始使用。

### E-20：回合结束时（第 64 页）

位于招式处理结束后，或主动不攻击而结束回合时；早于宝可梦检查，且不是检查的一部分。多个结束时效果由受影响卡牌的持有者决定其效果顺序。造成回合结束的特性仍应先完成自身效果。

### E-21：持续到下一个自己的回合结束（第 64–65 页）

从当前效果实际执行时起持续到下一个自己的回合结束，跨越中间的宝可梦检查。不要误写为仅下个自己回合有效，也不能略过当前招式内部实际生效的时点：伤害后才消除的特性不能反过来改变已经算完的伤害，却能影响后续受伤反应阶段。

### E-22：持续到下一个对手回合结束（第 65 页）

从当前自己回合内效果生效时起，持续到紧接着的对手回合结束；当前自己回合与该对手回合之间的检查也处于有效窗口。与仅写“下一个对手回合”不同。

### E-23：本回合由指定对象进化（第 65–66 页）

既要本回合发生进化，也要实际从牌文指定的前身进化；不能只看当前进化阶段或卡牌印刷的进化来源。复制该招式时，也检查实际使用者自己的进化历史。

这是历史条件而非可随换位清除的附加效果，回到备战再上场不抹去该事实。

### E-24：本回合从备战换上（第 66–67 页）

撤退、训练家效果、特性等导致的从备战进入战斗场都可满足，关键是本回合有该历史。多次满足不重复叠加一次性的后续；它是条件，不是每次上场额外叠一层招式效果。

### E-25：本回合使用过支援者（第 67 页）

检查本回合是否实际从手牌使出过支援者，满足则执行后续。不能只查看当前弃牌区有没有支援者推断此事。

### E-26：本回合回复过 HP（第 67 页）

实际回复至少 10 HP 才满足，不能把无伤时空点回复视作完成。多次回复也只满足一次条件；在备战回复、或回复后退回备战再上场，仍保留这一历史事实。

### E-27：明示可在某限制状态下攻击（第 67–68 页）

牌文允许在指定的通常禁止情形使用招式时，可在该情形使用；不处于该特殊情形，只要原本合法也可以用。许可范围只涵盖写明的限制，不据此免除能量或其他禁止条件。

### E-28：改变灼伤指示物数（第 68 页）

每次检查中的灼伤指示物数由生效效果改变。同类数值改变同时存在时取数值最大的一个执行一次，不相加；多个同名来源也不叠加。

### E-29：不受某类手牌出牌效果影响（第 68–69 页）

只保护指定对象不受所列出牌效果影响，不一定禁止该卡被使用；可执行的其他部分仍执行。必须区分真正被作用的是战斗宝可梦还是被选备战宝可梦，不能因备战免疫就一律挡住作用于战斗宝可梦的交换。

与“然后”串联时，前段因免疫完全未发生，会使依赖前段的后段不执行。

### E-30：以弃手牌为特性使用条件（第 69–70 页）

每卡按指定次数使用，必须能完成弃牌条件，也必须能够执行后续内容；不能只弃牌而无视预先已知无法执行的后段。不同卡有自己的次数，另有同名共享限制时从其规定。

### E-31：即将加入手牌前（第 70–71 页）

在抽牌或拿奖赏后已经看到卡面、但尚未正式加入手牌的窗口处理。多张有此效果的卡逐张完成各自处理，不合并为一次同时执行。

在这个窗口直接放上场或附着的卡，不算从手牌使出；不能触发只认手牌来源的效果。

### E-32：满足条件时采用特定招式费用（第 71–72 页）

条件满足后以牌文指定的属性和个数使用招式，原费用的增加或减少效果不再改变该特定要求；它不是把修改前的原费用简单减去一个数。并非同时绕过无法攻击等非费用限制。

### E-33：从自己手牌选择（第 72–73 页）

限定种类的选择允许少于指定数，甚至不选；未限定种类、要求任意卡牌的定数选择必须足额。不能把这种隐蔽区域少选权直接扩展为公开对象也可少选。

若卡文另有“必须弃指定数，否则招式失败”等结果条件，少选仍会造成规定的失败；有足够指定能量也可以选择不满足该条件并承担失败结果，不能据此得到成功的招式。

### E-34：从反面奖赏卡选择（第 73 页）

限定种类的检索同样可少选或不选；未限定种类而指定任意卡牌的数量则须足额。是否获准先查看、换入其他卡、以及查看后是否重洗，均由具体卡文决定；本条不赋予随时查看奖赏的权限。

### E-35：反面重洗指定集合（第 73–74 页）

不看正面地打乱集合，使双方不能掌握卡牌次序。集合完全为空时不能执行重洗。这个空集合边界与把卡放回牌库再洗的 E-36 不完全相同。

### E-36：返回牌库并重洗（第 74 页）

目标返回牌库后，不看正面地重洗；合并后仅一张也算完成重洗。牌文使手牌放回牌库时，即使此时无其他手牌，也可能通过实际存在的牌库重洗完成前段，不能机械套用“没有手牌所以前段必定失败”。

### E-37：某区域中拥有指定招式的宝可梦（第 74–75 页）

以该卡面写有的招式为准；未指定区域时，默认指自己场上。由特性或道具获准使用的额外招式、以及获准使用进化前招式，都不算当前卡拥有该招式。

### E-38：卡文直接决定胜败（第 75–76 页）

卡文可以在一般胜败条件之外直接决定该场对战的胜负。指南将这种决定胜负的效果排除在“施加于玩家的效果”之外，不能据玩家效果免疫等概念自行抵抗。

### E-39：指定基本能量卡名（第 76 页）

处理对象是卡牌名称匹配的基本能量卡，不能把提供同属性能量的特殊能量当成相同对象。旧系列未用引号标出的同类“基本某属性能量”用语与这一名称指定语义相同。

## 容易误读及需要保留的边界

| 位置 | 记录方式 |
| --- | --- |
| C-13，第 35 页；E-04，第 54 页 | 这两处比较伤害指示物数值时，“剩余 HP”应理解为该宝可梦当前有效的最大 HP。规则为累计伤害 ≥ 当前最大 HP，与 D-16 的剩余 HP ≤ 0 等价。 |
| E-07，第 56 页 | 说明开头谈普通附能和卡牌效果附能，后续触发细则以“从手牌”案例解释。应由具体触发文本决定来源限制，不把所有能量移动或转附概括成手牌附能。 |
