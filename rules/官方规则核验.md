## 2. 基础规则中容易误读的事实

### 2.1 可抽象的状态不等于玩家可直接观察的状态

| 容易误读的说法 | 官方资料支持的准确表述 |
| --- | --- |
| “自己拥有的卡都可以查看” | 自己的手牌可查看，但自己的牌库和奖赏卡也不能随意查看。牌库、手牌和奖赏卡属于非公开区域。 |
| “场上就是牌桌上的全部区域” | 规则中的“场上”特指战斗场与备战区，不包括手牌、牌库、弃牌区、奖赏卡。 |
| “所有卡的身份始终对所有人可见” | 开局战斗宝可梦和备战宝可梦先反面朝上放置，双方准备完毕后才翻正。 |
| “不能看对手手牌就不知道手牌数” | 可以确认对手手牌数量；双方持有手牌的数量没有一般上限。 |

来源：[区域定义与公开性](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules03/)、[开局摆放与手牌](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules04/)。

### 2.2 开局重抽不是任意换牌

开局需要 7 张手牌，选择基础宝可梦作为初始战斗宝可梦，可反面放置至多 5 只基础备战宝可梦，再放置 6 张反面奖赏卡。没有基础宝可梦时，需要展示手牌以供核实，再把手牌放回牌库并重洗、重抽。只有一方重抽时，对手可以选择补抽，最多为相应重抽次数，也可以不抽；双方都没有基础宝可梦时双方共同重来，不能把这种共同重来简单等同于单方重抽补偿。

网页中“放置宝可梦（1）”与“放置宝可梦（2）”重复展示相同描述，不是要求放置两只战斗宝可梦。

来源：[对战准备](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules04/)。更细的顺序见[进阶指南](https://www.pokemon.cn/misc/21231.html)第一部分 G，PDF 第 17–18 页（以下页码均为从 1 开始的 PDF 页序）。

### 2.3 “牌库为空”不等于立即败北

一般回合先强制从牌库上方抽 1 张，再选择进行其他操作。因正常抽牌抽到最后一张，不会立即败北；规则检查点是自己回合最初需要抽牌时，牌库已无卡可抽。效果抽牌、正常回合抽牌和牌库剩余数量，不能直接混成一个“空牌库即输”的判断。

来源：[对战方式：回合开始抽牌说明](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules05/)、[获胜方式](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules06/)。

### 2.4 一般限制、卡面例外和物理事实不能混为一谈

| 项目 | 一般规则及注意点 |
| --- | --- |
| 卡组 | 恰好 60 张；同名卡一般最多 4 张；基本能量不受该同名数量限制；至少含 1 张基础宝可梦。入门页面推荐的能量、训练家比例是构筑建议，不是合法性条件。 |
| 普通附能 | 一般每个自己的回合，可以从手牌给自己场上宝可梦附着 1 张能量卡。不能把这一限制直接解释为“全回合所有来源合计只能附着 1 张”。 |
| 进化 | 一般双方的最初回合不能进化；本回合刚出场、刚进化的宝可梦不能继续进化。不是全场每回合只能进化一只。 |
| 撤退 | 每个自己的回合一般 1 次；付出的是所需数量的能量，不是无条件丢弃同样数量的能量卡。卡牌效果导致的互换不能直接等同于撤退。 |
| 训练家 | 物品可使用任意张；支援者一般每回合 1 张，先攻首回合不能使用；竞技场一般每回合从手牌使出 1 张，不能使出与现存竞技场同名的卡。 |

来源：[卡牌种类](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules01/)、[所需物品](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules02/)、[对战方式](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules05/)、[构筑说明](https://www.pokemon.cn/tcg-deck-first-deck)。附能来源、能量卡与能量数量、互换与撤退的进一步区分见[进阶指南](https://www.pokemon.cn/misc/21231.html)第一部分 A-03、C，第二部分 C-03～C-05、C-09～C-10。

### 2.5 卡牌、宝可梦与附着关系不是同一概念

进化是把新的进化卡覆盖到对应宝可梦上。进化、回到备战区不会自动丢掉剩余能量或伤害指示物；但进化及回到备战区会清除相关特殊状态与招式效果。宝可梦昏厥时，其自身以及身上所有卡牌一同进入弃牌区。普通使用招式不会自动消耗所需能量，卡面另有指示时另论。

同名限制中的名称也不能简单等同于“同种宝可梦”：例如网页明确将“皮卡丘”和“皮卡丘 ex”视为不同卡牌名。

来源：[卡牌、进化和附着](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules01/)、[撤退后的保留与清除](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules05/)、[昏厥](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules06/)。进化保留项目和普通招式后的能量保留见[进阶指南](https://www.pokemon.cn/misc/21231.html)第一部分 A-05、C。

## 3. 结算时点与状态的独立核验

### 3.1 伤害与放置伤害指示物不能互换定义

基础网页给出的伤害顺序是：招式基础伤害及说明文、攻击方受到的伤害修正、弱点、抗性、受击方受到的伤害修正。伤害变成 0 或负数时，按相应步骤停止伤害计算。普通招式的伤害一般打向对手战斗宝可梦，特定卡面可以指定其他目标。

“造成伤害”和“以效果放置伤害指示物”最后可能都增加指示物，但不是相同的规则概念；不能据此自动套用相同的弱点、抗性、伤害防护。进阶指南将伤害计算条目与“身上放置伤害指示物”条目分开解释。

来源：[对战方式：伤害计算](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules05/)、[进阶指南](https://www.pokemon.cn/misc/21231.html)第一部分 A-01、第二部分 B 与 C-07。

### 3.2 宝可梦检查不是任一方回合内的自由操作阶段

每个玩家回合结束后都需要进行宝可梦检查，涉及双方。特殊状态检查的相对顺序是中毒、灼伤、睡眠、麻痹；混乱不在此时掷币处理。还要处理在检查时生效的特性或训练家效果，然后确认昏厥，再进入下一回合。

基础网页“处理顺序可依玩家喜好”不能读成“所有特殊状态随便排序”：进阶指南进一步说明，检查时的卡牌效果可安排在特殊状态检查之前或之后，效果间的顺序由受到效果的宝可梦持有者选择。进阶指南也明确宝可梦检查不属于双方任一回合。

来源：[宝可梦检查](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules07/)、[进阶指南](https://www.pokemon.cn/misc/21231.html)第一部分 F，PDF 第 16 页。

### 3.3 特殊状态的效果与叠加

| 状态 | 基础行为 |
| --- | --- |
| 中毒 | 每次检查一般放置 1 个 10 点伤害指示物；不阻止使用招式或撤退。 |
| 灼伤 | 每次检查先放置 2 个 10 点伤害指示物，再掷币；正面恢复，反面保留；不阻止使用招式或撤退。 |
| 睡眠 | 不能使用招式或撤退；每次检查掷币，正面恢复。 |
| 麻痹 | 不能使用招式或撤退；在自己的下一个回合结束后的检查恢复。 |
| 混乱 | 宣告招式时掷币；反面则招式失败，自身放置 3 个 10 点伤害指示物并结束回合；可以撤退。 |

中毒、灼伤可以与其他特殊状态并存。睡眠、麻痹、混乱彼此替代，不是三者同时保留。混乱造成招式失败时，官方教学明确不视作已经成功使用该招式。

来源：[特殊状态全文](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules07/)。

### 3.4 HP 到零和判定胜负都有处理时点

基础网页用剩余 HP 不大于 0 解释昏厥，并列出拿完奖赏卡、对手无可上场宝可梦、对手回合最初抽不到牌、对手认输等获胜情形。进阶指南进一步明确：在招式、特性、训练家效果处理期间满足胜负条件，也要先完成相关处理再判断胜负；昏厥确认也有指定时间点，不应把每一次指示物变化都理解成必须立即截断后续效果。

对手宝可梦昏厥后，拿的是自己的奖赏卡；通常 1 张，但特别规则可改变数量。例如宝可梦 ex 一般对应 2 张。奖赏卡可以任意顺序选择，拿取前不能随意查看其正面。

来源：[昏厥与胜负](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules06/)、[ex 规则](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules01/)、[进阶指南](https://www.pokemon.cn/misc/21231.html)第一部分 D、E，PDF 第 14–16 页。

## 4. 资料层级、版本与适用范围

### 4.1 卡面例外是官方规则结构的一部分

进阶指南第二部分 A 明确：卡牌说明与基本规则不同时，优先遵循卡牌说明；有更新后的效果时采用更新后的内容。禁止效果和允许效果重叠时，优先禁止效果。部分内容无法执行，不必然意味着整个效果不可使用；使用前置条件、可执行部分、数量选择、带有“然后”的依赖需要分别解释。

因此，普通教学中的“5 只备战”“每回合 1 次”等一般情形，不能脱离卡牌说明就推定为所有对局的无例外限制。

来源：[进阶指南](https://www.pokemon.cn/misc/21231.html)第二部分 A（PDF 第 19 页），以及第一部分对各类卡牌的解释。

### 4.2 页面内容存在覆盖范围差别，不能混成一个赛制

基础卡牌介绍页的“标准赛制中的拥有规则的宝可梦”当前以 ex 为例，并给出了“其他赛制特殊卡牌”的外链；特殊状态教学仍用 GX 招式解释“招式失败”。这说明教学示例可能覆盖不同卡牌历史，不能仅凭某个示例判断该卡一定属于当前标准赛制。

卡面上的赛制标记在基础网页中有解释。具体对战的可用标记、禁限卡、卡池和卡文版本取决于该对战适用的赛制。本次核验范围为简中官方资料。

来源：[卡类及赛制标记](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules01/)、[混乱与 GX 示例](https://www.pokemon.cn/tcg-rules-howtoplay?pageName=basic_rules07/)。

### 4.4 通用规则与逐卡裁定

基础教学与进阶指南提供通用玩法及说明文解释；具体卡牌仍受该卡有效说明及官方更新约束。通用条目和教学示例不构成全部卡牌的逐卡裁定集合。
