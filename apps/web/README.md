# PTCG 前端

React＋Vite 网页，使用 `packages/protocol` 的位置、视角和命令类型。牌桌操作和随机结果由后端执行，前端呈现返回的状态与记录。

从仓库根目录运行：

```sh
npm run dev:server
npm run dev:web
```

打开 `http://127.0.0.1:5173`。Vite 将 `/api` 代理到 `127.0.0.1:3001`；生产构建 `npm run build` 输出到本目录 `dist/`，由后端托管。

验证命令：

```sh
npm run check:web
npm run test:web
npm run build
```

## 使用

1. 在资料库导入 JSON 卡组，或打开非官方合成练习示例。
2. 创建 AI 对手时绑定卡组，初始策略可留空。策略修改保存成新版本，导出包含全部版本。
3. 新建人机对战或 AI 对战，按页面提示完成开局选择。
4. 人类对局从顶栏「牌桌操作」打开表单；点击牌桌卡牌／卡牌组选择来源，同源对象可多选，内部卡牌可从「展开卡牌组」选择。点击空槽或区域末尾可填入移动目标，也可在表单指定来源范围与目标。
5. 右侧固定记录面板保留全部原子记录，最新记录在上，内部滚动且不自动跳到最新；点击右下角上箭头返回最新。记录提供中文变化描述、原始记录和异议入口；回放进度从 0 到完整事件数，还原实际记录并展示撤销标记。

首页「策略评估」可选择双方 AI 的策略版本与被评估席位，点击运行版本 A。待该局结束，再选择版本 B 并点击运行对照。对手版本、起点与随机配置固定，评估期间保留参评策略版本。可结合多个起点的结果比较策略表现。

AI 观战默认全知、实时显示最新状态。1366×768 及以上桌面窗口使用一屏牌桌，双方区域面对面排布，手牌位于上下外沿，数量过多时仅该行横向滚动。放逐区与暂存区不在界面显示，底层数据及记录保留。牌面按 63:88 比例缩放，卡名、累计伤害、特殊状态和附着卡单独显示；悬停预览、点击固定卡牌详情，浮层不覆盖右侧记录。外观默认跟随系统，可在「更多」切换浅色／深色。小屏通过「对局记录」打开记录抽屉。

布局组件见 `MatchTable.tsx`，记录与历史解释见 `MatchHistory.tsx`、`event-presentation.ts`，对局样式集中在 `match.css`。

查看与展示的牌面出现在结果弹窗，原反馈保存在个人可读历史。人机对战使用人类玩家视角，赛后回放可切全知。对局从服务端加载，提交操作时显式指定人类席位。

系统配置页维护四种提示词、工具说明、纠错反馈及两种模型连接。API Key 仅配置服务端环境变量引用。「载入默认配置」只替换编辑器，保存后新局生效。
